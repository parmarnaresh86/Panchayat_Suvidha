NEXT STEPS TO COMPLETE SETUP:
==============================

STEP 1: CREATE LARAVEL PROJECT
-------------------------------
Open terminal and run:

cd /path/to/your/projects
composer create-project laravel/laravel panchayat-laravel
cd panchayat-laravel

STEP 2: INSTALL SANCTUM
------------------------
composer require laravel/sanctum
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"

STEP 3: COPY FILES TO LARAVEL PROJECT
--------------------------------------
Copy these files from 'laravel-backend' folder to your Laravel project:

FROM: laravel-backend/database/migrations/*
TO:   panchayat-laravel/database/migrations/

FROM: laravel-backend/app/Models/*
TO:   panchayat-laravel/app/Models/

FROM: laravel-backend/app/Http/Controllers/Api/*
TO:   panchayat-laravel/app/Http/Controllers/Api/

FROM: laravel-backend/app/Http/Middleware/AdminMiddleware.php
TO:   panchayat-laravel/app/Http/Middleware/AdminMiddleware.php

FROM: laravel-backend/routes/api.php
TO:   panchayat-laravel/routes/api.php

FROM: laravel-backend/config/cors.php
TO:   panchayat-laravel/config/cors.php

FROM: laravel-backend/bootstrap/app.php
TO:   panchayat-laravel/bootstrap/app.php

STEP 4: CONFIGURE ENVIRONMENT
------------------------------
1. Copy .env.example to .env:
   cp .env.example .env

2. Generate application key:
   php artisan key:generate

3. Edit .env file and set:
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=panchayat_db
   DB_USERNAME=root
   DB_PASSWORD=your_mysql_password

   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=password
   ADMIN_REGISTRATION_SECRET=admin-secret

   SANCTUM_STATEFUL_DOMAINS=localhost:5173

STEP 5: CREATE DATABASE
------------------------
mysql -u root -p
CREATE DATABASE panchayat_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

STEP 6: RUN MIGRATIONS
----------------------
php artisan migrate

STEP 7: SET UP FILE STORAGE
----------------------------
php artisan storage:link
mkdir -p storage/app/public/uploads
chmod -R 775 storage
chmod -R 775 bootstrap/cache

STEP 8: START LARAVEL SERVER
-----------------------------
php artisan serve

Server will run on: http://localhost:8000

STEP 9: UPDATE REACT FRONTEND
------------------------------
Edit: frontend/.env

Change:
VITE_API_URL=http://localhost:8000/api

Then restart React:
cd frontend
npm run dev

STEP 10: TEST THE API
---------------------
Test authentication:
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"password","email":"admin@example.com","role":"admin","adminSecret":"admin-secret"}'

curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"password","role":"admin"}'

Test public endpoints:
curl http://localhost:8000/api/village
curl http://localhost:8000/api/census
curl http://localhost:8000/api/panchayat

TROUBLESHOOTING:
================

Issue: CORS errors
Fix: Check config/cors.php has 'http://localhost:5173' in allowed_origins

Issue: Database connection failed
Fix: Verify MySQL is running and credentials in .env are correct

Issue: Token not working
Fix: Ensure Sanctum middleware is applied and SANCTUM_STATEFUL_DOMAINS is set

Issue: File upload not working
Fix: Run 'php artisan storage:link' and check storage permissions

Issue: Class not found
Fix: Run 'composer dump-autoload'

PRODUCTION DEPLOYMENT:
======================
1. Set APP_ENV=production in .env
2. Set APP_DEBUG=false in .env
3. Run: composer install --optimize-autoloader --no-dev
4. Run: php artisan config:cache
5. Run: php artisan route:cache
6. Run: php artisan view:cache
7. Set up proper web server (Nginx/Apache)
8. Configure SSL certificate
9. Update frontend VITE_API_URL to production URL
